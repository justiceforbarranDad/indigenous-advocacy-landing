## SECTION 5: PRINTING SPECIFICATIONS

### Page Layout
- **Margins:** 1 inch all sides (top, bottom, left, right)
- **Font:** Times New Roman or Arial, 12pt minimum
- **Line Spacing:** 1.5 or double-spaced
- **Page Numbers:** Bottom right corner, starting from page 1

### Double-Sided Printing

**Double-Sided (Front & Back):**
- ✓ All body text pages
- ✓ Accountability tracker
- ✓ Timeline of events
- ✓ Court documents
- ✓ Complaint templates
- ✓ Supporting documentation

**Single-Sided (Front Only):**
- ✓ Cover pages
- ✓ Title pages for each section
- ✓ Important notices
- ✓ Exhibit labels (A, B, C, etc.)

### Color Printing
- **Where Needed:**
  - ✓ Tab labels (color-coded)
  - ✓ Section headers (light color background)
  - ✓ Important notices (highlighted)
  - ✓ Charts/tables (if any)

- **Where Not Needed:**
  - ✗ Body text (black on white)
  - ✗ Regular pages (black and white)
